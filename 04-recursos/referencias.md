# Referencias Bibliográficas

## Libros Fundamentales

### Arquitectura y Modelado de Datos

1. **DAMA-DMBOK: Data Management Body of Knowledge (2nd Edition, Revised)**
   - Autor: DAMA International
   - Año: 2024 (revisión de mantenimiento; edición original 2017)
   - ISBN: 978-1634622349
   - Descripción: Marco de referencia definitivo para la gestión de datos. La revisión 2024 es la referencia vigente para la certificación CDMP desde octubre 2024.

2. **The Data Warehouse Toolkit (3rd Edition)**
   - Autor: Ralph Kimball & Margy Ross
   - Año: 2013
   - ISBN: 978-1118530801
   - Descripción: Guía práctica para diseño dimensional y Data Warehousing

3. **Building the Data Warehouse (4th Edition)**
   - Autor: W.H. Inmon
   - Año: 2005
   - ISBN: 978-0764599446
   - Descripción: Metodología Inmon para construcción de Data Warehouses

4. **Data Modeling Essentials (3rd Edition)**
   - Autor: Graeme Simsion & Graham Witt
   - Año: 2004
   - ISBN: 978-0126445510
   - Descripción: Fundamentos y técnicas de modelado de datos

5. **Data Architecture: A Primer for the Data Scientist**
   - Autor: W.H. Inmon & Dan Linstedt
   - Año: 2014
   - ISBN: 978-0128020449
   - Descripción: Arquitectura de datos para científicos de datos

### Calidad y Gobierno de Datos

6. **Data Quality: The Field Guide**
   - Autor: Thomas C. Redman
   - Año: 2001
   - ISBN: 978-1555582517
   - Descripción: Principios y prácticas de calidad de datos

7. **Non-Invasive Data Governance**
   - Autor: Robert S. Seiner
   - Año: 2014
   - ISBN: 978-1935504856
   - Descripción: Enfoque práctico para implementar gobierno de datos

8. **Data Governance: How to Design, Deploy and Sustain an Effective Data Governance Program**
   - Autor: John Ladley
   - Año: 2019
   - ISBN: 978-0128158319
   - Descripción: Guía completa para programas de gobierno de datos

### Arquitecturas Modernas

9. **Designing Data-Intensive Applications**
   - Autor: Martin Kleppmann
   - Año: 2017
   - ISBN: 978-1449373320
   - Descripción: Arquitecturas distribuidas y sistemas de datos modernos

10. **The Enterprise Big Data Lake**
    - Autor: Alex Gorelik
    - Año: 2019
    - ISBN: 978-1491931554
    - Descripción: Diseño e implementación de Data Lakes empresariales

11. **Cloud Data Management**
    - Autor: Ann L. Kuntz
    - Año: 2021
    - ISBN: 978-1484274897
    - Descripción: Gestión de datos en entornos cloud
