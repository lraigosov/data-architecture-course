# Contribuir al Curso de Arquitectura de Datos

## Tipos de Contribuciones

### 🐛 Reportar Errores
- Usa los GitHub Issues
- Incluye descripción clara del problema
- Agrega capturas de pantalla si es posible
- Indica el nivel y notebook específico

### 💡 Sugerir Mejoras
- Abre un Issue con la etiqueta "enhancement"
- Describe la mejora propuesta
- Explica el beneficio educativo

### 📝 Mejorar Documentación
- Corregir typos
- Clarificar explicaciones
- Agregar ejemplos
- Traducir contenido

### 🎓 Agregar Contenido
- Nuevos casos de uso
- Datasets adicionales
- Ejercicios prácticos
- Recursos de referencia

## Proceso de Contribución

### 1. Fork del Repositorio
```bash
git clone https://github.com/lraigosov/data-architecture-course.git
cd data-architecture-course
```

### 2. Crear una Rama
```bash
git checkout -b feature/mi-contribucion
```

### 3. Hacer Cambios
- Sigue las guías de estilo (ver abajo)
- Prueba que los notebooks funcionen
- Documenta tus cambios

### 4. Commit
```bash
git add .
git commit -m "Descripción clara del cambio"
```

### 5. Push y Pull Request
```bash
git push origin feature/mi-contribucion
```
Luego crea un Pull Request en GitHub.

## Guías de Estilo

### Notebooks
- Markdown para explicaciones teóricas
- Código limpio y comentado
- Outputs visibles (ejecuta antes de guardar)
- Secciones numeradas claramente
- Referencias al final

### Documentación
- Markdown para archivos .md
- Títulos claros y jerárquicos
- Ejemplos prácticos
- Enlaces funcionando

### Código Python
```python
# PEP 8 style guide
# Comentarios claros
# Variables con nombres descriptivos
# Funciones documentadas
```

### Nomenclatura
- Archivos: `snake_case.md`, `01_titulo_notebook.ipynb`
- Carpetas: `kebab-case` o `snake_case`
- Variables: `snake_case`
- Constantes: `UPPER_CASE`
